# ANUM FARID — Portfolio Implementation

This version uses the actual project assets already present in `public/projects/`.

## Included experience

- ANUM FARID fixed consistently in the top-right
- VISUALS WITH PURPOSE opening
- About, approach, and What I Bring sections based on the supplied portfolio reference
- Elevate Solutions architectural construction sequence
- Elevate camera/office transition using the supplied building and office artwork
- Signature Coffee cinematic scene with falling beans, rotating product artwork, coffee pour and steam
- Remaining selected work presented as a sideways 3D/depth gallery
- Warm beige/charcoal base palette with a coffee-toned cinematic section
- Responsive styling

## Run

From the project folder:

```powershell
npm install
npm run dev
```

Then open the Local URL printed by Next.js (for example `http://localhost:3001` if 3000 is already occupied).

The archive intentionally does not include `node_modules` or `.next`; npm recreates the dependencies/build cache.
